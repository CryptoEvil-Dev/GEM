# GEM
Graphic Environment Manager
**GEM**: Менеджер графических окружений. Позволяет выбирать графическую оболочку в интерактивном графическом режиме.
### Библиотеки
- SDL2 (Отрисовка графики)
- yaml-cpp (Парсинг yaml файла конфигурации)
# GEM.yaml

### Конфигурация GEM
**mouse-src**: Путь до изображения мыши (По умолчанию белый кружок с чёрной обводкой)
**background-color**: Цвет фона (По умолчанию 30 30 45 255)
**background-image**: Фон-изображение (По умолчанию нет)
---

### Конфигурация оболочек
**name**: Название оболочки
**sorce**: Путь до исполняемого файла оболочки
**description**: Описание оболочки
**image**: Путь до изображения оболочки
**background-color**: Фон плитки оболочки
**background-image**: Фон-Изображение оболочки
---
